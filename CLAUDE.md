# Agent instructions for ytSort

## Git

Do not run `git commit`, `git push`, open a pull request, or merge, unless
explicitly told to do so in that turn. Make and leave code changes
uncommitted by default; wait for an explicit instruction (e.g. "commit",
"push") before touching git state.

## Documentation

Only update `.md` files (README, this file, other docs/help files) at the
point a push is actually done - not opportunistically alongside every code
change. Batch documentation updates together with the push they accompany.
